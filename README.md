# Turbo Pixel GP

An arcade-style 8-bit top-down racing game that runs in the browser.

## ▶ [Play it now](https://splocker.github.io/turbo-pixel-gp/)

No install or download needed — the link above opens the game straight from GitHub Pages.

## Run locally

Open `index.html` in any modern browser.

## Tests

```sh
npm test
```

Requires Node 22+.
